# 読み方と表示環境

[連載目次へ](../README.md)

## GitHubのMarkdownで読む

リポジトリのREADMEから各回を開き、Preview表示を使う。RawやCode表示は原稿テキストを見るためのものであり、図は表示されない。各回の冒頭と末尾に、前回・目次・次回のリンクがある。

## HTMLで読む

GitHub Pagesが有効なら、公開URLのトップページが目次になる。手元で再生成した場合は `_site/index.html` をブラウザで開く。サーバー起動は不要である。全8回を一つのファイルで読む場合は `_site/complete.html` を開く。どちらも外部通信をしない。

## 再生成する

Python 3.11以降とPandoc 3.xを使う。Python標準ライブラリだけを使うため、pipによる追加導入は不要である。Pandocの導入方法は[公式インストール案内](https://pandoc.org/installing.html)を参照する。

```sh
python --version
pandoc --version
python scripts/validate.py
python scripts/build.py
```

WindowsでPythonコマンドが `py` の場合は `py -3 scripts/build.py` とする。HTMLを作る前にMarkdownの検査を行い、警告を残したまま公開しない。

## 表示の設計

本文は1行がおよそ45字になる幅（720px）、16px、行間1.8で組んである。本文は1文ごとに改行する原稿の呼吸をそのまま残しているので、段落の間隔は詰めてある。節見出しは太字のみで、縦線や下線は引用や表との区別のために使わない。各回の冒頭と末尾にある枠つきの行が前後の回へのリンクで、末尾には次回の題名を添えている。図は本文幅に収め、細い枠で本文と区別する。電話幅では図を横にスクロールでき、タップすると原寸のSVGが開く。

## 図と注の読み分け

挿絵は原典の転載ではなく、本連載の説明のために作成した概念図である。対数の時間軸に並べた帯や周期の異なる波は「時間尺度の違い」の視覚的な記号であり、長さや周波数は代表値を単純化したものである。矢印は必ずしも因果を表さない。キャプションに示す前提を併せて読む。

脚注の出典は、その理論や研究の参照先であり、原文の引用ではない。研究の裏づけがある主張と、本連載が置いた整理・仮説（意識の遅延テーゼ、凝縮説、拡張記憶、多重時計原理、未完了相としての現在、マルチ時間スケール）は、本文中で区別している。本文で「元資料」と呼んでいるのは、連載の土台となった著者の覚え書きであり、公刊された文献ではない。
