# 編集・保守ガイド

[連載目次へ](../README.md)

## 原本と生成物の責務

| パス | 責務 | 編集方法 |
| --- | --- | --- |
| `chapters/*.md` | 各回の本文、図の参照とキャプション、脚注、前後リンク | 直接編集する |
| `series.json` | 連載の順序、題名、副題、概要、部（`parts`）、各回の図の一覧（`figures`）と出典の対応 | 本文変更と同じPRで整合させる |
| `assets/illustrations/*.svg` | 本文から参照する独立した挿絵 | `draw_figures.py` を編集して再生成する |
| `scripts/draw_figures.py` | 表紙と各回の図（計24点）を再現する図形コード | 原則としてこちらを編集する |
| `references/sources.json` | 文献の書誌と今回の確認範囲 | 一次情報と確認状況を分けて更新する |
| `references/bibliography.md` | 読者向けの文献一覧 | `scripts/bibliography.py` で再生成する |
| `guides/SERIES-DESIGN.md` | 連載の設計書（各回の核となる主張、概念の反復） | 構成を変えるときに更新する |
| `site-src/styles.css` | HTML閲覧用の見た目 | 本文内容を持たせない |
| `scripts/build.py` | MarkdownをHTMLへ変換 | 原本を改変しない |
| `scripts/validate.py` | 本文・参照・SVG・出典の構造検査 | 検査規則を保守する |
| `scripts/check_html.py` | HTMLの相対リンク・アンカー・外部依存を検査 | 生成後に実行する |
| `tests/` | 検査・変換の回帰試験 | 成功例と失敗例を両方持つ |
| `_site/` | ブラウザ用生成物 | 直接編集せず再生成する |

## 変更の最小手順

```sh
# Markdown、図の生成コード、出典を編集した後
python scripts/draw_figures.py
python scripts/bibliography.py
python scripts/validate.py
python -m unittest discover -s tests -v
python scripts/build.py
python scripts/check_html.py
```

SVGを直接修正すると次の図再生成で上書きされる。長期保守する変更は `draw_figures.py` に反映する。回数は `series.json` の `chapters` の数で決まり、検査・ビルド・目次はそこから読む。別の連載を同じ型で加える場合は、別フォルダに自分の `series.json` と目次を置き、`scripts/build.py` の `SERIES_FILES` に登録する。

## 各回の型

各回は次の順で構成する。冒頭の日常的な場面か短い問い、概念の導入（定義は太字で1文）、核となる主張（1回につき1文で言い切れる主張を1つ）、前回までの議論との接続、次回への橋（「次回｜第N回」の予告）。本文は原稿の1文1段落の呼吸を保ち、文章そのものは改変しない。

回をまたぐ概念は五つある。「瞬間と持続」（2・6・8回）、「時間スケールギャップ」（2・3・7・8回）、「意識の遅延テーゼ」（3・4・6・8回）、「未完了相としての現在」（4・6・8回）、「マルチ時間スケール」（6・7・8回）。改稿するときはこれらの位置と文言を崩さない。

## 図の置き方と密度

図は、その内容を説明し終えた段落の直後に置く。次の節の内容を先に見せる図は、分割して該当する節へ移す。1枚につき主張は1つ、パネルは2枚まで、ラベル文は10個前後までとする。1回あたり2〜4枚を目安とし、4枚を超えるなら本文側の説明を疑う。

ファイル名は `NN-x-slug.svg`（回番号と枝番）とし、`series.json` の `figures` に本文での登場順に並べる。Markdownから `![代替テキスト](../assets/illustrations/04-a-reflex-vs-deliberation.svg)` のように相対参照し、直後に `*図N-k：前提の説明*` というキャプションを置く。`k` は回内の通し番号で、検査は `figures` の数と順序に一致することを確かめる。SVGコードを本文へ貼り付けない。

SVGには `viewBox`、`role="img"`、`title`、`desc` を持たせる。`script`、`foreignObject`、外部画像、外部フォント、イベントハンドラは入れない。グラデーションなど `url(#id)` による内部参照は許す。矢印や色だけに意味を依存させず、ラベルでも区別する。時間尺度を並べる図は対数軸を使い、代表値であることをキャプションに書く。主色は深い青（`#2b5f9e`）、副色は琥珀（`#c7792b`）、補助に青緑と紫を使う。日本語の表示は閲覧環境のフォントを利用し、フォントファイルは同梱しない。

## 出典の管理

文献は本文の脚注 `[^friston-2010]` と末尾の「参考文献・注記」の脚注定義でつなぐ。同じIDを `sources.json` と `series.json` の `sources` でも使う。検査は、脚注の使用と定義、`series.json` の一覧、`sources.json` の存在が一致することを確かめる。

機械検査はURLの構文とローカル参照を検査する。外部URLの生存や、文献が主張を本当に支えるかは編集レビューで確認する。原典の語句を引用する場合は、引用符、引用範囲、ページを明示し、長文転載はしない。

## 本連載独自の名称

「意識の遅延テーゼ」「凝縮説」「拡張記憶」「多重時計原理」「サリエンス・スレッシュホールド」は本連載の整理であり、公刊された文献の用語ではない。本文では「本連載では〜と呼ぶ」と明示し、脚注でもその旨を記す。連載の土台となった著者の覚え書きを本文から参照しない（「元資料」という表記は使わない）。
